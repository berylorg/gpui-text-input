# External GUI Specs

This document registers externally owned GUI widget specifications consumed by `gpui-text-input`.
`Spec root` paths are relative to this repository root and are documentation lookup paths, not Cargo
dependency mechanisms.

Spec root: ../gpui-scrollbar/doc/gui/widgets
